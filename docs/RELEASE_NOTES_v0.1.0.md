Mikro 0.1.0 is an Android arm64 preview of the V2 gallery cleaner.

This build includes TinyCLIP categories and similarity suggestions, opt-in YuNet/SFace people grouping, a local preference model and the swipe review flow. Review and confirm each deletion in the app before the OS receives it.

Requirements: Android 7.0 (API 24) or later on arm64.

This APK is built in GitHub Actions with Flutter 3.47.9 and uses the Android template's debug signing key. It is for installation/testing, not Play Store distribution or an in-place upgrade over a differently signed build. It has not been installed or performance-tested on a physical Android phone. People grouping can make mistakes and stays off until enabled. Background scans and store purchases are not included in this preview.
