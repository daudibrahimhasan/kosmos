# Bundled sample photos

These are stock photos from images.unsplash.com, downloaded for the explicitly labeled sample-library preview on November 4, 2026. No app screen fetches them remotely. Each JPEG contains its original source URL in a provenance comment.

Sample timestamps, sizes, video placeholders and screenshot hints are fixtures. Photo categories, semantic embeddings, hashes, sharpness scores and optional face vectors are computed from the bundled image bytes by the same local AI pipeline used for imported or native photos.

Font licenses are in assets/fonts. App icons are original geometric dot arrangements rendered locally.
